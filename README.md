# 🏝️ Survival Unity 3D

**Survival Unity 3D** — трёхмерный симулятор выживания от первого лица в открытом мире на базе игрового движка **Unity** и языка программирования **C#** с использованием **Universal Render Pipeline (URP)**.

Игрок оказывается на необитаемом острове, где ему предстоит добывать природные ресурсы, следить за жизненными показателями персонажа, создавать инструменты и возводить собственное укрытие для защиты от угроз окружающей среды.

---

## 🎮 Основные игровые механики

* **Система жизненных показателей (Vitals System):** динамический контроль здоровья, голода, жажды и выносливости персонажа с плавной регенерацией и штрафами при истощении.
* **Добыча ресурсов (Resource Gathering):** интерактивное взаимодействие с объектами окружения (рубка деревьев, добыча камня, сбор плодов и веток) с учётом типа экипированного инструмента.
* **Инвентарь и экипировка (Inventory & Equipment):** слотовая система хранения предметов с поддержкой стаков, быстрым переключением инструментов в руках и использованием расходников (еда, вода, аптечки).
* **Система крафта (Crafting System):** создание новых инструментов, оружия и строительных компонентов по рецептам из собранных ресурсов.
* **Модульное строительство (Building System):** размещение фундаментов, стен, дверей, костров и кроватей с визуальным предпросмотром (ghost-префабы) и проверкой коллизий.
* **Динамическая смена дня и ночи (Day/Night Cycle):** плавное изменение освещения, положения солнца и атмосферы острова в реальном времени.
* **ИИ животных и врагов (AI Behavior):** навигация существ по `NavMesh`, реагирование на игрока (преследование или бегство) и боевая система.

---

## 🛠️ Технологический стек

* **Движок:** Unity (2020.3 LTS / 2022.3 LTS)
* **Язык программирования:** C#
* **Рендеринг:** Universal Render Pipeline (URP)
* **Ввод и интерфейс:** Unity Input System, TextMeshPro (TMP), Unity UI (Canvas)
* **Навигация ИИ:** Unity NavMesh

## 🕹️ Управление

| Клавиша / Действие | Описание |
| :--- | :--- |
| **`W` `A` `S` `D`** | Передвижение персонажа |
| **`Shift`** | Ускорение (бег, расходует выносливость) |
| **`Space`** | Прыжок |
| **`Мышь`** | Обзор камерой от первого лица |
| **`ЛКМ`** | Использование экипированного предмета / атака / добыча |
| **`E`** | Взаимодействие с объектами / подбор ресурсов |
| **`Tab` / `I`** | Открыть / закрыть инвентарь и меню крафта |
| **`B`** | Режим строительства |
| **`1` – `9`** | Быстрый выбор слота на панели быстрого доступа |
| **`Esc`** | Меню паузы |

## 📂 Структура проекта

```text
Assets/
└── Survival 3D/
    ├── Animations/      # Анимации персонажа, инструментов и существ
    ├── Materials/       # Материалы и шейдеры URP
    ├── Models/          # 3D-модели окружения, ресурсов и построек
    ├── Prefabs/         # Готовые префабы предметов, ресурсов и UI-элементов
    ├── Scenes/          # Игровые сцены (главное меню и остров)
    └── Scripts/         # Исходный код на C#
        ├── Building/    # Логика строительства и предпросмотра объектов
        ├── Environment/ # Ресурсы, смена дня и ночи, погодные эффекты
        ├── Items/       # Подбор, взаимодействие и ScriptableObjects предметов
        ├── Placeables/  # Интерактивные постройки (кровать, костёр, верстак)
        └── Player/      # Контроллер игрока, инвентарь, экипировка и статы
